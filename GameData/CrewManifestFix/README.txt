Crew Manifest Fix 0.2.0

Fixes for Crew Manifest 6.5.1.1: no extra toolbar button (and background copy of itself) every
time a flight scene is loaded, a close button in the corner of the Crew Manifest window, and no
log line on every frame while the window is open. Crew Manifest's own files are not modified.
Requires Crew Manifest 6.5.1.1 (exactly; does nothing on other versions) and Harmony 2.2.1+.

AI disclosure: this mod was written in collaboration with Claude Code (Anthropic),
model Claude Opus 5.5. The code, configs and documentation were generated by the AI;
the author defined the idea and requirements, reviewed the design and tested it in game.
